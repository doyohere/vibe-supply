# Vibe Supply

바이브코딩 수업용 참고 갤러리입니다. 생활 속 작은 불편을 AI와 함께 풀어낸 앱 27개를 모았습니다.

- `index.html`: 갤러리 페이지 (카드에 마우스를 올리면 실제 화면 녹화가 재생됩니다)
- `media/`: 카드용 썸네일 (`.jpg` 정지 화면, `.webp` 움직이는 화면)
- `gif/`: 슬라이드나 노션에 넣을 수 있는 GIF 버전

## GitHub Pages로 올리기
1. 새 저장소를 만들고 이 폴더의 파일을 그대로 올립니다.
2. Settings > Pages에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

## 카드 고치기
`index.html` 아래쪽 `APPS` 목록에서 한 줄씩 추가하거나 지우면 됩니다. 썸네일은 `media/<id>.jpg`, `media/<id>.webp` 이름으로 넣습니다.

링크와 화면은 2026-10-23 기준으로 확인했습니다.
